## Notice policy

- **Runtime dependencies** are pinned centrally in `Directory.Packages.props`, license-reviewed, and
  must pass the Native AOT publish gate for `win-x64` and `linux-x64` before they enter
  `RayBork.Engine`. The milestone that first uses a package's features owns its feature-level AOT
  validation; the status column records that boundary honestly.
- **Test and tooling packages** are JIT-only. They are not part of the runtime publish graph and are
  not covered by the runtime AOT gate, but they are still license-reviewed before adoption.
- **Every dependency row records** the exact pinned version, license, purpose, and runtime, test, or
  tooling classification. Floating versions are not allowed; transitive dependencies are governed
  by the pinned graph of their direct package.
- **A dependency change updates this file in the same pull request** as the version or package
  change. Review covers license, version, purpose, classification, and AOT status.
- **Full license texts ship with the packages.** NuGet packages carry their own license metadata
  and license files, and in-box .NET APIs are covered by the .NET runtime notices and SDK. This file
  summarizes the inventory and points at those texts; it does not replace them.
- **Incompatible licenses are rejected.** A dependency whose license cannot be distributed with an
  MIT-licensed project is not adopted. Do not vendor dependency source without a notice update and
  review.
- **Versions move deliberately.** A version bump is a dependency change and follows the rules above.

M5 status: the M5 primitive and collision surface is exercised end to end by the
`samples/PrimitiveGallery` AOT gate, which opens a window, builds its only texture procedurally, and
draws the M5 primitive surface through the built-in `/shaders/primitive` and `/shaders/mesh` programs
on `win-x64` and `linux-x64`. The gate mounts the engine's built-in pack and decodes its texture and
shader descriptors; it does not load a user pack or custom data, so that coverage remains with the
M3 and M4 gates and in the unit and GPU suites. The M5 present pass also carries the HDR-aware AgX
rework; its derived source is recorded under [Derived shader source](#derived-shader-source). The
M4 `samples/Castle` gate remains a buildable and publishable sample: it mounts a baked pack, loads a
multi-part `Model` with a KTX2 texture and the built-in mesh shader, and draws the scene through the
bindless instanced path. `samples/HelloInterop` remains the M1-M3 diagnostic host for the host,
input, time, logging, renderer, and asset-loading surface. `Silk.NET.Vulkan`, `SDL3-CS`, `PolyType`,
`Nerdbank.MessagePack`, `System.IO.Hashing`, and
the logging packages are exercised by the M5 gate or its built-in pack and descriptor path. The bake
gains the JIT-only TOML, image, block-encoding, shaderc, and glTF packages below; they never enter a
runtime project or an AOT publish graph. The built-in pack generator uses the same bake packages at
engine build time and emits only a generated byte array. Both AOT publishes must finish with zero
AOT/trim warnings.

## Derived shader source

`src/RayBork/RayBork.Engine/Shaders/Present.frag.glsl`,
`src/RayBork/RayBork.Engine/Internal/Graphics/AgxToneMap.cs`, and
`src/RayBork/RayBork.Engine/Internal/Graphics/AgxCurveParameters.cs` contain a port of the AgX tone
mapper and the allenwp tonemapping curve. These sources are not vendored; the following attribution
and licenses apply.

- **[Godot Engine](https://github.com/godotengine/godot) 4.7** —
  `servers/rendering/renderer_rd/shaders/effects/tonemap.glsl` and
  `servers/rendering/storage/environment_storage.cpp`, MIT. The combined Rec.709 to Rec.2020 and
  AgX inset matrix, the combined inverse AgX outset and Rec.2020 to Rec.709 matrix, the allenwp-curve
  use, and the AgX curve-parameter derivation are ported from Godot 4.7. Copyright (c) 2014-present
  Godot Engine contributors. Copyright (c) 2007-2014 Juan Linietsky, Ariel Manzur.
- **EaryChow's AgX LUT generator** — [EaryChow/AgX_LUT_Gen](https://github.com/EaryChow/AgX_LUT_Gen),
  referenced by Godot as the source of the AgX base transform that Blender uses
  (`AgXBasesRGB.py`). RayBork references the transform through the Godot port and does not
  redistribute the LUT generator or its generated LUT data.
- **allenwp tonemapping curve** — Allen Pestaluky, 2025,
  [An Adjustable Tonemapping Curve for Variable / Extended Dynamic Range](https://allenwp.com/blog/2025/05/29/allenwp-tonemapping-curve/),
  MIT. RayBork adapts the curve with Godot's `0.18` crossover and the CPU-derived `toe_a`, `slope`,
  and `w` parameters. Copyright (c) 2025 Allen Pestaluky.

## Maintaining this file

- Add or remove a row when a package is added or removed; group the rows by classification and keep
  the runtime, platform, and test/tooling tables intact.
- Keep versions identical to `Directory.Packages.props`; a review that finds a drift blocks merge.
- Keep the license value to the SPDX identifier used by the package metadata.
- Update the status paragraph when a milestone turns a deferred AOT status into an exercised gate.
- System components such as the Vulkan loader and the optional validation layer are recorded in the
  platform table; they are not NuGet packages and are never redistributed with RayBork.
- If a package's license text is not included in its distribution, add the license text here or
  reject the package.
